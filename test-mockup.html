🌳 Prueba del Mockup Hero

1. Vista Desktop (1280×720)

Abre mockup-hero.html en pestaña nueva a tamaño normal. Luego:

  • ✓ Scroll hacia abajo lentamente
  • ✓ Observa cómo la foto "con árboles" se revela de abajo a arriba
  • ✓ Scroll hacia arriba — la imagen se oculta de nuevo
  • ✓ Sin lag, sin parpadeos
  • ✓ Las tarjetas de texto flotantes se ven claramente

2. Vista Mobile (375×812)

Opción A: Usa Chrome DevTools (Ctrl+Shift+M) en /mockup-hero.html

Opción B: Abre en un teléfono real a http://<tu-ip>:8080/mockup-hero.html

  • ✓ El handle circular pulsa 3 veces al cargar
  • ✓ Arrastra el handle hacia la izquierda → foto "con árboles" desaparece
  • ✓ Arrastra hacia la derecha → foto se revela completamente
  • ✓ El movimiento es suave (60fps)
  • ✓ Puedes ver las etiquetas "ANTES" y "DESPUÉS"
  • ✓ Scroll hacia abajo muestra las tarjetas de texto
  • ✓ El hint "Arrastra para comparar" desaparece después del primer drag

3. Sin Errores en Consola

Abre Developer Tools (F12) → Console:

  • ✓ No hay mensajes rojos de error
  • ✓ No hay advertencias sobre undefined
  • ✓ Animaciones fluidas sin jank

4. Características Técnicas Verificadas

  • ✓ Desktop: position: sticky (no fixed)
  • ✓ Mobile: touch-action: pan-y para gestos correctos
  • ✓ Mobile: 100svh respeta chrome de iOS Safari
  • ✓ Desktop: requestAnimationFrame para smooth scroll
  • ✓ Breakpoint at 768px para cambio automático mobile ↔ desktop
  • ✓ Handler de rotación de dispositivo
💡 Nota: Si quieres probar con tu propio servidor: 
cd d:/Vibecoding/1000_arboles
python -m http.server 8080
# Abre http://localhost:8080/mockup-hero.html
